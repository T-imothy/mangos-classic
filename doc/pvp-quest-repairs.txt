Classic PvP quest repairs, 2026-10-14

Quest kill and object objectives now admit battleground raid membership, as
quest item objectives already do. Outdoor raid restrictions remain native.
AV rewards notify the actual active battleground only after native quest
reward state is committed; membership, faction and map must match.
Armor scraps upgrade all seven graveyard defender locations.

AB admitted flag interactions now award the five personal assault markers,
shared by all level-bracket variants. Own banners, loading, wrong instance
and nonmember interactions award nothing. Capturing five bases completes
both the four-base and five-base objective spells.

Empty Stables (7001/7027) uses the native tame item spells (21794/21866).
The actual successful aura caster owns the follower, and only that player
can deliver the appropriate living animal near the correct stable master.
Quest cancellation, transfer or lost tame aura releases the animal. Delivery
awards objective credit once and retains native quest reward/menu handling.
Wild animals retain EventAI charge/rend behavior.
Tamed followers do not acquire new enemies while being delivered.

Fallen Sky Lords (7301/7302) now awards the existing six invisible commander
discovery markers when an eligible player reaches native interaction range
with line of sight in their actual active AV instance. Personal progress
prevents repeated credit; faction, quest, membership and loading checks
reject unrelated visits. No commander or optional army is spawned.

Install the matching ClassicDB Updates/ManTech/20261014_av_quest_trophies.sql
with this binary, not against an older core. It adds two missing Wanted
bounty turn-ins, repairs ten corpse loot conditions and binds four stable
NPC templates and six existing discovery markers. Conditions 65001-65008 must be free or already identical to
this migration. Loot references use 16-bit condition IDs. Existing unrelated
conditions 293-300 and native quest rewards/level brackets are not rewritten.

The race condition evaluator now handles Corpse explicitly, preserving
Unit race/class behavior and rejecting corpse class predicates.

Verification executes native function bodies with narrow fixtures, followed
by a full native build/CTest. The data migration is separately exercised
twice on connection-local temporary clones. These checks are not live AV
playthroughs or proof that every optional battleground event is implemented.

Known existing limits: air, rider and ground assaults plus Ivus/Lokholar
activation still have native TODO event handlers. Contribution counts and
quest rewards now work; the missing armies/rituals are not claimed repaired.
Retired/internal quest rows without starters are not enabled as content.
